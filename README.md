# HR Attrition Analysis

## Objective
Analyze employee attrition patterns and identify workforce retention challenges.

## KPIs
- Total Employees

- Attrition Rate
- Average Employee Age

## Tools Used

- HR Analytics
- Dashboard Development

## Key Insights
- Attrition trends differ across departments.
- Employee demographics influence retention.
- Attrition rate provides a key HR performance indicator.
